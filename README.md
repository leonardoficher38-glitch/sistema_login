# 🔐 Sistema de Login Python

Sistema de autenticação simples feito em Python com limite de tentativas no terminal.

## Funcionalidades

- Verificação de senha com comparação direta
- Limite de 3 tentativas antes de bloquear o acesso
- Contador regressivo de tentativas restantes
- Mensagens de erro e acesso permitido

## Como usar

1. Clone o repositório:
   git clone https://github.com/leonardoficher38-glitch/sistema-login.git

2. Execute o arquivo:
   python "sistema de login simples.py"
